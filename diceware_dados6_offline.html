Como funciona

Jogue 5 dados e anote os números na ordem. O código de 5 dígitos (11111 a 66666) é convertido em um índice 0-7775. Se o índice for < 6144 (3×2048), a palavra BIP39 é wordlist[índice % 2048]. Se índice ≥ 6144, descarte e role novamente. Isso garante distribuição uniforme entre as 2.048 palavras.

23~253 bits23 palavras por dados + 1 checksum = seed de 24

Cada palavra adiciona 11 bits (log₂ 2048).

Descarte (índice ≥ 6144)

5 dados de 6 lados geram 7776 combinações (6⁵). Como 7776 não é divisível por 2048, usamos apenas os primeiros 6144 resultados (3×2048). Os 1632 restantes (índices 6144-7775) devem ser descartados para manter a distribuição uniforme. Probabilidade de descarte: ~21%.

Dicas de segurança

A ordem importa — não reordene para "soar melhor". É parte da aleatoriedade.
A lista é pública — seu poder está nos SEUS dados, não em escondê-la.
Use dados de qualidade — dados de cassino (arestas vivas) são ideais.
Tudo offline — role, anote no papel, busque na lista impressa ou neste arquivo sem internet.
Checksum — a última palavra (12ª ou 24ª) deve ser calculada com ferramenta BIP39; não é aleatória.
